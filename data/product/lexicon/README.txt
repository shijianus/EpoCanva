EpoCanva product lexicon (W1 internal alpha)
============================================

The TSV in this directory is generated by tools/data/build_product_lexicon.py from the
source pinned in data/manifests/english-pilot.sources.lock.json in the EpoCanva source
repository:

  English Speller Database (ESDB), Alt12Dicts package, file alt12dicts/2of12full.txt,
  commit 7bbe293425d48a1210bf17aaf156b28ade5c2de1 (rel-2018.04.16).

The shipped epocanva_en_alpha.provenance.txt beside this README records the source commit,
source and output SHA-256, conversion policy and exclusion tally for the exact file in
this package.

The source file is placed in the public domain by Alan Beale (alt12dicts/README:28-29),
with a request for acknowledgment (alt12dicts/README-orig:1441-1446). The AGID carve-out
does not reach 2of12full.txt; AGID files are not inputs.

The product artifact is produced by its own deterministic conversion. It is not a copy of
build/english-pilot/epocanva_en_pilot.tsv, which remains test-only. The generated
epocanva_en_alpha.provenance.txt records the source commit, source and output SHA-256,
conversion policy and exclusion tally.

Before any redistribution outside this internal alpha, the project owner and legal review
must settle the jurisdictional statement recorded in docs/compliance/english-pilot-data.md
and the still-undecided EpoCanva project licence (AGENTS.md section 8).
