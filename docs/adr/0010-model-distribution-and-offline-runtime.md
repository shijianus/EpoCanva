# ADR 0010 — 模型分发：元数据默认可见，权重默认不下载

## 状态

Accepted（约束）。**尚未实现**：没有模型目录、没有下载器、没有离线导入。
内测期规则先于实现固定下来，避免实现时临时发明字段与流程。

## 背景

神经模型是可选增强（ADR 0008），但"可选"很容易在实现时退化为"顺手下载"。
同时，模型权重、tokenizer 与推理框架各自有独立许可，不能混为一谈。
Windows 的 TSF DLL 不能获得隐式联网能力，Android 的输入法 APK 需要保持
不申请 `INTERNET` 权限。

## 决策

1. **元数据与权重分离**：模型目录（`model_id`、名称、来源、修订、大小、许可、
   语言/领域、内存估计、安装状态）可以默认随产品提供；**权重默认不下载**。
2. **可重复身份**：清单必须记录 `upstream_repository` + 精确 `revision`/commit +
   `sha256`。禁止 `latest` 或浮动分支作为构建身份。
3. **用户主动获取**：下载前展示来源、大小与许可；支持取消；校验 SHA-256；
   失败不破坏已安装模型；不得静默下载其他模型。
4. **存储分离**：模型文件与个人学习数据分别存放；删除模型不删偏好，
   删除偏好不删模型（除非用户明确选择）。
5. **Windows 边界**：下载由用户明确启动的**独立模型管理程序**负责。
   TSF DLL、语言引擎与预测执行进程不得因此获得隐式联网能力。
6. **Android 边界**：优先"浏览器下载 + 系统文件选择器导入"，
   使输入法 APK 可继续不申请 `INTERNET` 权限。
   **不得**声称同一 APK 中某个无网络 Activity 能独立撤销整个应用已声明的权限。
7. **离线导入必须可验证**：导入时校验格式、版本、tokenizer 身份与哈希；
   不兼容或损坏的文件直接拒绝并保留原状态。
8. **环境不允许下载时**：只实现目录、校验与离线导入，
   不执行任何模型获取。缺少许可证明即标记 BLOCKED，不绕过。

## 清单字段（最小集）

```text
model_id                 稳定 ASCII 标识
display_name             显示名，不参与查找
upstream_repository      官方来源 URL
revision                 精确 commit / tag 解析后的 SHA
artifact_path            包内相对路径
sha256                   权重文件哈希
license                  模型许可标识
model_family / tokenizer_identity / quantization
supported_languages      语言标签列表
supported_domains        领域标签列表
runtime_compatibility    推理框架与版本
estimated_memory / estimated_storage
installation_state       未安装/已安装/校验失败/不兼容
```

字段类型与版本约束由实际实现确定；本 ADR 只固定语义。

## 备选方案与未采纳原因

| 方案 | 未采纳原因 |
| --- | --- |
| 随安装包内置权重 | 体积、许可与"默认不下载"要求同时冲突 |
| 首次启动自动下载推荐模型 | 隐式获取，违反用户主动选择 |
| 用 `latest` 或 `main` 作为修订 | 不可复现，也无法绑定许可与哈希 |
| 在输入法 APK 内加下载 Activity 并申请 INTERNET | 权限是应用级的，无法按页面撤销 |
| 把模型放在学习数据目录 | 删除语义会互相牵连 |

## 后果

**正面**

- 用户在看到大小与许可前不会被消耗流量或磁盘。
- 模型身份可审计、可复现。
- 两个平台都能保持各自的离线承诺。

**负面 / 成本**

- 内测期需要用户手动放置文件，体验不如一键安装。
- 模型格式与推理框架兼容性需要独立测试矩阵，尚未建立。

## 重新评估条件

1. 正式发布需要统一模型源与目录服务时，必须重新审查分发许可与签名链。
2. 平台提供"按组件授权网络"的能力（当前 Windows 普通进程与 Android 应用级权限都不提供）时。
3. 离线导入格式稳定并有第三方模型适配需求时。
